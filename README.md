# Bayesian Sampling Game

An interactive, game-based prototype for exploring human judgment, decision-making, and Bayesian sampling.

## Overview

This project explores the possibility of using an interactive game environment to study how people gather information, update beliefs, and make decisions.

The long-term goal is to combine computational cognitive modelling with game-based interventions.

## Research Objectives

- Develop an engaging, interactive experimental paradigm.
- Investigate heuristic reasoning and Bayesian sampling.
- Examine how information sampling influences judgments and decisions.
- Explore potential sampling-based interventions.

## Current Status

Early-stage prototype / Proof of Concept.

The experimental design, computational modelling, and intervention mechanisms are still under development.

## Future Development

- Record participant responses and sampling behaviour.
- Integrate computational models of Bayesian sampling.

## Note

This prototype is intended for research discussion and demonstration purposes. It is not yet a validated experimental task or intervention.
